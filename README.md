# Student_performence_Analysis_NumPy
A Python-based Student Performance Analysis project built using NumPy. It analyzes students’ marks across multiple subjects and calculates total marks, averages, class toppers, lowest performers, subject-wise averages, failed students, student rankings, class average, and standard deviation.
This project is a simple Student Performance Analysis System developed using Python and NumPy. It takes student names and their subject-wise marks as input and performs various statistical operations to analyze academic performance.


The project demonstrates the practical application of NumPy arrays, mathematical operations, conditional filtering, and sorting.

🚀 Features

* Total Marks: Calculates the total marks obtained by each student.
* Student Average: Calculates the average marks of each student.
* Class Topper: Identifies the student with the highest total marks.
* Lowest Performer: Identifies the student with the lowest total marks.
* Subject-wise Average: Calculates the average marks in each subject.
* Failed Students: Identifies students who scored below 33 in any subject.
* Student Ranking: Ranks students according to their total marks in descending order.
* Class Average: Calculates the overall average marks of the class.
* Standard Deviation: Measures the variation in students’ total marks.
